# 学生学业风险预测分析报告

**分析工具**: Python, scikit-learn, pandas, matplotlib, seaborn, numpy

## 运行指南

**运行方式**: 以压缩文件为根目录，直接运行src目录下的 Runner.py即可

**注意事项**:

- 数据集文件Data应与src目录在同一目录下
