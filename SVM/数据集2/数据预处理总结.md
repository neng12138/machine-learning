## 三、数据预处理步骤

### 3.1 预处理流程

```
原始数据 → 缺失值处理 → 重复值处理 → 异常值处理 → 数据标准化 → 输出
```

### 3.2 缺失值处理

由于数据说明文档提到原始数据中存在缺失值，且已被预处理：
- **类别属性**：使用众数填充
- **数值属性**：使用均值填充

```python
# 类别属性众数填充
categorical_cols = ['A1', 'A4', 'A5', 'A6', 'A8', 'A9', 'A11', 'A12']
for col in categorical_cols:
    mode_val = df[col].mode()[0]
    df[col] = df[col].replace(['?', 'NA'], mode_val)

# 数值属性均值填充  
numeric_cols = ['A2', 'A3', 'A7', 'A10', 'A13', 'A14']
for col in numeric_cols:
    mean_val = df[col].mean()
    df[col] = pd.to_numeric(df[col], errors='coerce').fillna(mean_val)
```

### 3.3 重复值处理

```python
df = df.drop_duplicates()
```

### 3.4 异常值处理（IQR 方法）

采用 IQR（四分位距）方法对异常值进行截断处理：

```python
for col in numeric_cols:
    Q1 = df[col].quantile(0.25)
    Q3 = df[col].quantile(0.75)
    IQR = Q3 - Q1
    lower_bound = Q1 - 1.5 * IQR
    upper_bound = Q3 + 1.5 * IQR
    
    # 将异常值截断到边界值
    df.loc[df[col] < lower_bound, col] = lower_bound
    df.loc[df[col] > upper_bound, col] = upper_bound
```

**处理结果**：
| 属性 | 处理异常值数量 |
|------|--------------|
| A2 | 9 |
| A3 | 10 |
| A7 | 22 |
| A10 | 8 |
| A13 | 9 |
| A14 | 112（因存在极大值100001） |

### 3.5 数据标准化（Z-score）

对数值属性进行 Z-score 标准化：

```python
for col in numeric_cols:
    mean = df[col].mean()
    std = df[col].std()
    df[col] = (df[col] - mean) / std
```

**标准化后特征**：
- 均值 ≈ 0
- 标准差 ≈ 1
